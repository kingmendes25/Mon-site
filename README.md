## Comment utiliser

1. **Ouvrir le site**  
   Double-cliquez sur `index.html` ou ouvrez-le avec un navigateur (Chrome, Firefox, Safari…).

2. **Mettre en ligne**  
   Uploadez tout le dossier sur un hébergeur (Netlify, Vercel, GitHub Pages, Hostinger, etc.).

3. **Personnaliser les liens boutique**  
   Dans `index.html`, cherchez :
   - `id="link-chariow"` → remplacez `href="https://chariow.com/"` par **votre vrai lien Chariow**
   - `id="link-maketou"` → remplacez `href="https://www.maketou.com/"` par **votre vrai lien Maketou**

4. **Ajouter un nouveau service**  
   Dans `index.html`, section `#services` :
   - Copiez un bloc `<article class="service-card">...</article>`
   - Collez-le juste avant la carte « Nouveau service »
   - Modifiez le titre, la description, les points et le lien WhatsApp
